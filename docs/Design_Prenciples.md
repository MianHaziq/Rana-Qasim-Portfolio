# Portfolio Design Principles

## Mission

This portfolio must look like it was designed by a professional UI/UX designer and built by a senior frontend engineer.

The goal is NOT to create a generic developer portfolio.

The goal is to create a memorable personal brand.

Anyone viewing the website should think:

> "This looks custom designed."

NOT

> "This looks AI generated."

---

# Design Style

Use a premium, modern and minimal design language.

Inspired by the quality of:

- Apple
- Vercel
- Linear
- Stripe
- Framer
- Notion
- GitHub

Do NOT copy these websites.

Instead, follow their design philosophy:

- Excellent spacing
- Professional typography
- Clean layouts
- High attention to detail
- Balanced white space
- Subtle animations
- Minimal distractions

---

# Color Palette

Use timeless colors.

Primary colors:

- White
- Black
- Slate
- Gray
- Charcoal
- Navy

Accent

Choose ONE accent color only.

Examples:

- Indigo
- Royal Blue

Avoid:

- Rainbow colors
- Neon colors
- Random gradients
- Excessive glow
- Poor contrast

The UI should feel professional enough for recruiters and clients.

---

# Typography

Use professional fonts.

Preferred:

- Inter
- Geist
- Manrope
- Sora

Typography should have:

- Proper hierarchy
- Comfortable spacing
- Balanced font sizes
- Excellent readability

Avoid oversized headings.

---

# Layout

Every section should have breathing room.

Prioritize:

- Alignment
- Grid consistency
- White space
- Visual rhythm

Never make sections feel cramped.

---

# Components

Every component should feel handcrafted.

Buttons

Cards

Inputs

Navigation

Footer

Timeline

Project Cards

Everything should share the same design language.

---

# Animations

Animations should improve UX.

Use:

- Fade
- Blur
- Scale
- Stagger
- Smooth easing

Avoid:

- Flashy effects
- Continuous bouncing
- Excessive floating objects
- Distracting animations

The animation should be noticed only because everything feels smooth.

---

# Hero Section

The hero should immediately communicate professionalism.

Requirements:

- Strong typography
- Premium profile image
- Balanced composition
- Clean CTA buttons
- Elegant background

Avoid generic "Hello World" layouts.

---

# Projects

Projects should look like real products.

Cards should include:

- Clear hierarchy
- Technologies
- Nice hover effects
- Optional image
- GitHub
- Live Demo

---

# Contact

The contact section should feel premium.

Not just a simple form.

Include:

- Beautiful layout
- Nice spacing
- Validation
- Micro interactions

---

# Dark Mode

Dark mode should feel polished.

Not just inverted colors.

Adjust:

- Shadows
- Contrast
- Borders
- Backgrounds

Professionally.

---

# Overall Feel

The final result should feel:

- Premium
- Elegant
- Trustworthy
- Modern
- Fast
- Clean
- Professional
- Unique

Never feel like a generic AI-generated template.
